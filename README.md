# Open-Alpha 0.3 — Blue Lock RP Tactical Board

Open-Alpha 0.3 — развиваемая тактическая доска для матчей Blue Lock RP.

## Уже реализовано в интерфейсе

- Адаптивная доска для компьютеров и смартфонов.
- Демонстрационные составы, перетаскивание игроков и перемещение мяча.
- Режимы выбора, передачи, движения и перемещения камеры.
- Отрисовка траекторий между двумя точками.
- Карточки игроков и генератор статистики.
- Несколько локальных вкладок матчей, схемы и экспорт JSON.
- Локальное сохранение и индикатор матча с ID/ссылкой.
- Таймер матча с запуском и паузой, счёт, переключение таймов.
- Журнал событий: голы, таймы и события, добавленные ГМ вручную.
- Отмена и повтор последних изменений расстановки (до 80 шагов).
- Discord OAuth через Supabase при условии корректной конфигурации проекта.
- Клиентская интеграция с Supabase Edge Function для загрузки/сохранения поля и Realtime-канал для обновлений.

## Важное различие: интерфейс и безопасность

Наличие кнопки или вызова функции ещё не означает, что функция доступна безопасно в production. Проверка роли ГМ/капитана, командные ограничения, доступ к статистике и совместная работа должны подтверждаться серверными Edge Functions и политиками RLS. Не считайте локальный выбор Blue/Red/наблюдатель механизмом безопасности.

## Онлайн-режим: что необходимо проверить/доделать

1. Развернуть и проверить Edge Function `match-data` на проекте Supabase.
2. Убедиться, что схема БД включает участников матча, роли/команды, приглашения и безопасные политики RLS для совместного доступа.
3. Проверить, что Realtime-канал допускает только участников конкретного матча и что изменения корректно обрабатываются при переподключении.
4. Проверить все действия на сервере: движение фишек, изменение счёта/таймера, управление участниками, просмотр и изменение характеристик.
5. Проверить Discord OAuth callback и проверку Discord guild/role через серверную Edge Function.
6. Не хранить токены бота или service-role key в браузере либо репозитории.

## Инструменты ГМ

В текущей версии интерфейса есть таймер, счёт, смена тайма, журнал событий, ручное добавление события и undo/redo расстановки. Следующие шаги: сохранять журнал/счёт/таймер в облаке, добавить заметки ГМ, права на управление матчем и полноценный откат событий.

## Мобильный интерфейс

Нижняя панель адаптирована под три кнопки. Осталось провести ручную проверку на реальном телефоне: touch drag, масштабирование поля, прокрутка панелей, поведение клавиатуры и safe-area.

## Настройка Supabase

1. Создайте проект Supabase и примените SQL-миграции из `supabase/migrations`.
2. Включите Discord OAuth в Authentication → Providers и укажите redirect/callback URL.
3. В Cloudflare задайте `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`. Не используйте service-role key во frontend.
4. Разверните Edge Functions из `supabase/functions` и задайте серверные secrets, которые указаны в документации соответствующей функции.
5. Настройте RLS так, чтобы доступ выдавался только владельцу и проверенным участникам матча.

## Локальный запуск

Нужен Node.js 20 или новее:

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Для Cloudflare Pages: preset Vite, команда сборки `npm run build`, папка результата `dist`.
