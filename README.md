# Blue Lock RP — Tactical Board

Первая версия интерфейса тактической доски.

## Что работает
- Отдельная адаптация для компьютера и смартфона.
- Две тестовые команды и демонстрационные карточки игроков.
- Перетаскивание игроков мышью или касанием.
- Перемещение мяча нажатием на поле.
- Линии передачи и движения по двум точкам.
- Кнопка «Сохранить» сохраняет раскладку в локальном браузере текущего устройства.
- Экспорт текущей раскладки в JSON.
- Вкладки нескольких матчей с отдельными составами, мячом и линиями.
- Индикатор матча с ID и ссылкой для подключения.
- Теневая копия: позиции игроков и мяча зеркалятся с исходного матча, а линии на копии остаются независимыми для обсуждения тактики.

## Пока не реализовано
- Общая realtime-база для синхронизации через интернет между разными пользователями и устройствами.
- Discord OAuth и проверка ролей.
- Синхронизация между пользователями/устройствами пока не подключена: индикатор синхронизируется между открытыми вкладками одного браузера через BroadcastChannel. Для полноценного онлайн-режима нужно настроить Supabase и правила доступа.
- Реальная матчёвая логика и расчёт вероятностей.

Не добавляйте пароли базы данных и секретные ключи в frontend или репозиторий.

## Запуск локально
Нужен Node.js 20 или новее:

```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
```
Результат появится в `dist`.

## Публикация на Cloudflare Pages
Подключите этот GitHub-репозиторий. Настройки сборки:
- Framework preset: `Vite`
- Build command: `npm run build`
- Build output directory: `dist`

Это только frontend-прототип. Подключение Supabase и авторизацию добавим отдельно, с правильными правилами доступа.
